# DR-001 - Reporte de defecto simulado

## ID

DR-001

## Título

El badge del carrito muestra una cantidad diferente a la esperada después de agregar un producto.

## Aplicación

Sauce Demo

## Módulo

Inventario / Carrito de compras

## Severidad

Media

## Prioridad

Media

## Precondiciones

- El usuario debe ingresar a Sauce Demo.
- El usuario debe iniciar sesión correctamente.
- Se deben utilizar las credenciales:
  - Usuario: `standard_user`
  - Contraseña: `secret_sauce`

## Pasos para reproducir

1. Ingresar a Sauce Demo.
2. Iniciar sesión con el usuario `standard_user`.
3. Verificar que inicialmente no exista el badge del carrito.
4. Agregar el primer producto disponible.
5. Verificar el valor mostrado en el badge del carrito.
